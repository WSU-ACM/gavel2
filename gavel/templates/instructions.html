How participant voting works

1
Review your first assigned project. There is nothing to compare it with yet, so select “{{ finished_button_text }}” when you are ready to continue.
2
For each new project, compare it with the project you reviewed immediately before it. Choose the stronger project using the hackathon organizers’ criteria.
3
Consider each comparison carefully. After you submit a choice, you cannot change it. You will never be asked to compare your own team’s project.
4
{% if not virtual %} Skip a project only when its team is absent or presenting to another participant. {% endif %} Keep reviewing projects until Gavel tells you that none are currently available. Follow any next steps from the hackathon organizers.

Ask a hackathon organizer if you have questions about the voting criteria or project rules.
